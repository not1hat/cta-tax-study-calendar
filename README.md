# CTA 税法学习日历

税法一、税法二的本地优先学习日历。网页使用原生 HTML、CSS、JavaScript；每日任务、已核验题目和页面实际引用的 PDF 均保存在本仓库。入口为 `index.html`。

## 使用与数据

- 打开日历，进入已生成的日课。选择题在提交后显示答案；仅答错时展示解析。应用题留待外部 GPT 评测。
- 作答可导出 JSON 和 Markdown；外部评测完成后可在对应日期导入。网站不连接 GPT，也不自动生成纠错课程。
- 学习记录保存在当前浏览器的 `localStorage`，网站不会跨设备自动同步。换设备前请从首页导出完整备份 JSON，再在新设备导入。导入会覆盖新设备当前记录。
- 日课中的 PDF 链接统一指向 `assets/pdfs/`；导图小图位于 `assets/maps/`；28 份已回填的历史学习总结位于 `assets/history/`。题目数据保留来源文件与 PDF 页码。

## 发布

GitHub Pages 使用 `main` 分支根目录发布。根目录的 `.nojekyll` 保证静态资源按原路径提供。发布后须核查网页、每日任务、PDF 链接、作答及评测导入导出、刷新留存和备份恢复。

仓库不含浏览器本地存储中的作答、评测和备份文件，也不含原工作目录下完整的 SVIP 资料包；仅纳入日课页面当前实际链接的 22 份 PDF 和 28 份历史学习总结。
