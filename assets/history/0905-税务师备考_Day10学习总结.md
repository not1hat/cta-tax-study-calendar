## 三、当日知识点与学习内容

### （一）税法（一）节点1：发票与扣税凭证

| 知识框架 | 学习内容（简写） |
|---|---|
| 发票功能 | 交易、会计核算、税收管理的重要凭证；区分普通发票与增值税专用发票 |
| 专用发票 | 一般纳税人抵扣的重要凭证；向自然人销售等法定情形不得开具专票 |
| 红字与作废 | 开票有误、销售折让、中止、退回等按规则红冲；不得任意作废规避监管 |
| 抵扣凭证 | 专票、机动车销售统一发票、海关进口增值税专用缴款书、完税凭证等 |
| 计算抵扣 | 购进农产品等按法定扣除率计算进项；与凭票抵扣严格区分 |
| 异常凭证 | 失控、走逃、比对不符、缺联、上传异常等风险；A类纳税人可在10个工作日内申请核实 |

### （二）税法（一）节点2：征收管理与全章串联

| 知识框架 | 学习内容（简写） |
|---|---|
| 纳税义务时间 | 收讫销售款或取得索款凭据；先开发票的为开票当日；进口为报关进口当日 |
| 纳税期限与地点 | 固定业户机构所在地；非固定业户应税行为发生地；进口由海关征收 |
| 预缴 | 异地建筑、不动产转让、不动产出租、房地产项目预售等按规定预缴 |
| 一般计税 | 应纳税额＝当期销项税额－当期进项税额；不得抵扣项目作进项转出 |
| 简易计税 | 应纳税额＝销售额×征收率；不得抵扣进项税额 |
| 全章逻辑 | 征税范围→纳税人→税率/征收率→销售额→销项→进项→一般/简易→预缴→优惠→征管 |
| 综合计算案例 | 销项25万元，可抵扣进项16万元，其中非正常损失对应3万元应转出，另有简易计税2万元：一般计税应纳税额＝25－（16－3）＝12万元；合计＝12＋2＝14万元 |

### （三）税法（二）节点1：房地产开发企业所得税

| 知识框架 | 学习内容（简写） |
|---|---|
| 完工标准 | 开发产品竣工证明材料已报备案；或已开始投入使用；或已取得初始产权证明，三者孰早 |
| 未完工收入 | 销售未完工开发产品取得收入，先按预计计税毛利率计算预计毛利并计入应纳税所得额 |
| 完工调整 | 产品完工后及时结算计税成本，将实际毛利与预计毛利差额作纳税调整 |
| 收入方法 | 一次性全额、分期、银行按揭、委托销售等按相应规则确认收入 |
| 成本对象 | 可否销售、分类归集、功能区分、定价差异、成本差异、权益区分等原则确定 |
| 六项开发成本 | 土地征用及拆迁补偿费、前期工程费、建筑安装工程费、基础设施建设费、公共配套设施费、开发间接费 |

### （四）税法（二）节点2：企业所得税优惠

| 知识框架 | 学习内容（简写） |
|---|---|
| 公共基础设施 | 符合条件项目自取得第一笔生产经营收入所属年度起，三免三减半 |
| 小型微利企业 | 符合条件企业按25%计入应纳税所得额、20%税率，实际税负5%（现行阶段性口径） |
| 研发加计扣除 | 未形成无形资产按规定加计扣除；形成无形资产按规定比例摊销；烟草、住宿餐饮、批零、房地产、租赁商务、娱乐等行业不适用 |
| 创业投资 | 符合条件投资满2年，按投资额70%抵扣应纳税所得额，不足可结转以后年度 |
| 加速折旧/一次扣除 | 技术进步或强震动高腐蚀资产可缩短年限或加速；符合条件设备器具可一次性税前扣除 |
| 专用设备抵免 | 环保、节能节水、安全生产专用设备投资额的10%可抵免当年企业所得税，不足可结转5年 |
| 小微计算案例 | 应纳税所得额280万元，符合小微条件：企业所得税＝280×25%×20%＝14万元，实际税负5% |

### （五）税法（二）节点3：企业所得税征收管理

| 知识框架 | 学习内容（简写） |
|---|---|
| 纳税年度 | 公历1月1日至12月31日；中途开业、终止使实际经营期不足12个月的，以实际经营期为一个纳税年度 |
| 预缴 | 分月或分季预缴，自月份或季度终了之日起15日内报送预缴申报表并预缴税款 |
| 汇算清缴 | 年度终了之日起5个月内报送年度申报表，汇算清缴，结清应缴应退税款 |
| 终止经营 | 实际经营终止之日起60日内办理当期企业所得税汇算清缴 |
| 清算 | 清算期作为独立纳税年度；清算所得按规定计算企业所得税 |
| 跨地区汇总 | 总机构统一计算，分支机构分摊缴纳；常用分摊权重为营业收入35%、职工薪酬35%、资产总额30% |
| 分摊案例 | 某分支三因素占比依次为30%、45%、50%，综合分摊比例＝30%×35%＋45%×35%＋50%×30%＝41.25% |

### （三）结课综合后测

1. **第4题：异常凭证核实期限**  
   纳税信用A级纳税人取得异常凭证且已经申报抵扣、出口退税或消费税扣除时，可先不作转出处理；税务机关告知之日起**10个工作日内**提出核实申请。关键词是“工作日”，不能按自然日计算。你的答案B错误，正确答案C。

2. **第10题：增值税预缴情形**  
   增值税预缴并不只包括异地建筑、不动产出租和房地产开发企业预收款。纳税人跨县（市、区）转让其取得的不动产，通常也应在不动产所在地按规定预缴，再向机构所在地主管税务机关申报纳税。因此D也应选；你的ABC漏选D，正确答案ABCD。
