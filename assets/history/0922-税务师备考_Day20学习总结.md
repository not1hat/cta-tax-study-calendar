## 三、七道错题详解与复测

| 轮次/题号 | 错因 | 正确判断与复测抓手 |
|---|---|---|
| 课前2 | 漏选“包装物作价销售”，只想到押金规则。 | 应税消费品连同包装物出售，包装物售价并入销售额；押金另分普通应税品、酒类及逾期规则。复测时先问“售价还是押金”。 |
| 收尾4 | 选2万元，相当于只把18+2乘10%，漏算进口环节消费税。 | 计税价格＝(18+2)÷(1－20%)＝25万元；车购税＝25×10%＝**2.5万元**。亦可先算消费税5万元，再用18+2+5。 |
| 收尾9 | 选1.8万元，相当于只扣减1年；题设已使用满2年。 | 计税价格按完整年限每满1年减10%；20×(1－2×10%)×10%－0＝**1.6万元**。 |
| 收尾16 | 将来源国有固定基地误扩展为可对全球所得征税。 | 典型独立个人劳务条款只允许来源国对**归属于固定基地**的所得征税。居民国的征税权另看其国内法及协定。 |
| 收尾17 | 将达到183天门槛误扩展为来源国可对全球所得征税。 | 按本课所讲典型条款，来源国只可对**在该国进行活动取得**的所得征税。做具体题仍须核对适用协定。 |
| 收尾19 | 漏选国际客运的基础情形。 | 船舶或飞机经营国际客运、货运均属于国际运输收入；程租、期租船舶与湿租飞机亦属之。 |
| 收尾20 | 漏选符合条件的“附属”干租收入例外。 | 独立光租、干租通常不属国际运输收入；若满足公告规定的附属业务条件，可**视同**国际运输收入。先判断是否附属，再判断归类。 |
