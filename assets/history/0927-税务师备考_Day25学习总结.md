## 三、税法一学习内容

### 微节点1：基本医疗保险与生育保险

| 知识点 | 核心结论 |
|---|---|
| 职工基本医疗保险参保 | 用人单位及职工属于基本参保主体；领取失业保险金期间的失业人员由失业保险基金列支基本医疗保险费 |
| 职工医疗保险缴费 | 用人单位和职工共同缴纳，职工个人应缴部分由单位代扣代缴 |
| 医保基金不支付范围 | 应由工伤保险基金支付、应由第三人负担、应由公共卫生负担、境外就医的费用 |
| 生育保险缴费 | 用人单位缴费，职工个人不缴纳 |
| 医疗生育合并 | 生育保险基金并入职工基本医疗保险基金，统一征缴 |
| 生育保险待遇 | 包括生育医疗费用和生育津贴 |
| 生育津贴基数 | 按职工所在用人单位上年度职工月平均工资计发 |

节点检测：6/6，100%。

### 微节点2：工伤、职业伤害、失业保险及社保征缴

| 知识点 | 核心结论 |
|---|---|
| 工伤保险缴费人 | 由用人单位缴纳，职工个人不缴纳 |
| 工伤保险费率 | 实行行业差别费率和浮动费率制度 |
| 工伤保险应缴额 | 本单位职工工资总额×确定的缴费比例 |
| 职业伤害保障对象 | 通过平台接单并以平台名义提供出行、即时配送、同城货运等劳动的新就业形态人员 |
| 职业伤害缴费人 | 平台企业按规定申报并缴纳 |
| 职业伤害计算 | 应缴费订单数×每单缴费额 |
| 失业保险缴费 | 用人单位与职工共同缴纳；比例按当地现行政策或题目给定比例计算 |
| 社保登记 | 单位成立后30日内登记；用工后30日内为职工登记 |
| 申报缴费 | 单位自行申报、按时足额缴纳；职工个人部分由单位代扣代缴 |
| 未申报处理 | 按单位上月缴费额的110%暂行确定，补办申报后据实结算 |

计算案例：

1. 即时配送平台20,000单，每单0.07元，职业伤害保障费＝20,000×0.07＝1,400元。
2. 单位工资总额1,000,000元，失业保险单位费率0.7%，单位应缴额＝1,000,000×0.7%＝7,000元。

节点检测：6/6，100%。

税法一节点检测合计：12/12，100%。

## 四、税法二学习内容

### 微节点1：房产税基本制度

| 知识点 | 核心结论 |
|---|---|
| 地域范围 | 城市、县城、建制镇、工矿区；不包括农村 |
| 房产判断 | 具有屋面和围护结构，可供生产、工作、学习、娱乐、居住或储藏物资 |
| 非房产 | 独立于房屋之外的围墙、烟囱、水塔、变电塔等不属于房产 |
| 一般纳税人 | 产权所有人 |
| 全民所有 | 经营管理单位缴纳 |
| 产权出典 | 承典人缴纳 |
| 特殊情形 | 产权人、承典人不在所在地，或产权未确定、租典纠纷未解决时，由代管人或使用人缴纳 |
| 从价税率 | 1.2% |
| 从租税率 | 一般为12%；个人出租住房等符合条件时为4% |
| 自建房屋 | 建成之次月起计征 |
| 委托建房 | 办理验收手续之次月起计征；验收前已使用、出租或出借的，从当月计征 |
| 新建商品房 | 交付使用之次月起计征 |
| 存量房 | 权属登记机关签发权属证书之次月起计征 |
| 出租、出借 | 交付房产之次月起计征 |
| 征收管理 | 按年征收、分期缴纳，在房产所在地纳税 |

节点检测：7/7，100%。

### 微节点2：减免税、计税依据与应纳税额

#### 1. 减免税

| 类别 | 核心结论 |
|---|---|
| 基本免税 | 国家机关、人民团体、军队自用；财政拨付事业经费单位自用；宗教寺庙、公园、名胜古迹自用；个人所有非营业用房产 |
| 危险房屋 | 经鉴定毁损不堪居住或属于危险房屋的，停止使用后免税 |
| 大修房屋 | 连续停用半年以上的，大修期间免税 |
| 基建临时房屋 | 工棚、材料棚、休息棚等在施工期间免税 |
| 开发企业商品房 | 出售前且未自用、出租、出借时原则上不征；已经使用或出租、出借的应征 |
| 六税两费 | 符合条件的小规模纳税人、小型微利企业和个体工商户房产税减半至2027年12月31日 |
| 农产品市场 | 专门用于农产品交易的房产免税至2027年12月31日；混合经营按面积比例划分 |
| 孵化器等 | 符合条件的科技企业孵化器、大学科技园、备案众创空间相关房产免税至2027年12月31日 |
| 社区服务 | 符合条件的社区养老、托育、家政服务用房免税至2027年12月31日 |
| 商品储备 | 符合条件的商品储备管理公司及直属库承担储备业务的自用房产免税至2027年12月31日 |

#### 2. 计税方法

| 情形 | 计税方法 |
|---|---|
| 从价计征 | 房产原值×（1－原值减除比例）×1.2% |
| 不足全年 | 房产原值×（1－减除比例）×1.2%÷12×应税月数 |
| 一般从租 | 不含增值税租金收入×12% |
| 个人出租住房 | 不含增值税租金收入×4% |
| 免租期间 | 产权所有人按房产余值从价计征 |
| 无租使用 | 实际使用人按房产余值代为缴纳 |
| 投资联营共担风险 | 被投资企业从价计征 |
| 投资联营固定收入 | 投资人按固定收入从租计征 |
| 融资租赁 | 承租人按房产余值从价计征 |
| 独立地下工业建筑 | 房屋原价的50%～60%作为应税原值，再按当地减除比例计税 |
| 独立地下商业及其他建筑 | 房屋原价的70%～80%作为应税原值，再按当地减除比例计税 |

#### 3. 房产原值

| 项目 | 处理 |
|---|---|
| 账簿房屋原价 | 按原价计入，不扣折旧 |
| 不可分割附属设备、配套设施 | 计入房产原值 |
| 更换附属设备 | 新设备价值计入，同时扣减原设备价值 |
| 经常更换的易损零配件 | 更换后不增加房产原值，原零配件价值也不扣除 |
| 房屋所占土地地价 | 按规定计入房产原值 |

计算案例：

1. 原值1,200万元，旧中央空调80万元更换为140万元新设备，减除比例30%：调整后原值＝1,260万元；房产税＝1,260×70%×1.2%＝10.584万元。
2. 原值600万元房产，减除比例30%，1—2月免租，3—12月不含税租金100万元：免租期从价税额0.84万元，收租期从租税额12万元，全年合计12.84万元。
3. 独立地下工业建筑原价500万元，应税原值比例60%，减除比例30%：500×60%×70%×1.2%＝2.52万元。

节点检测：6/8，75%。

- 漏选“符合条件的商品储备管理公司承担储备业务的自用房产免税至2027年12月31日”。
