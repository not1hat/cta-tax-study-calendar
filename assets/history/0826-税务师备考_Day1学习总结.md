## 一、税法一：税法基本原理

### 1. 税法基本原则
已学习并掌握：
- 税收法律主义
  - 课税要素法定
  - 课税要素明确
  - 依法稽征
- 税收公平主义
- 税收合作信赖主义
- 实质课税原则

课堂理解要点：
- 即使税务机关与纳税人双方协商一致，也不能擅自改变法定课税要素或征收程序。
- 税务机关正式作出的错误解释，在符合条件时可适用税收合作信赖主义。
- 关联交易按经济实质进行调整，体现实质课税原则。

### 2. 税法适用原则
已学习并掌握：
- 法律优位原则
- 特别法优于普通法原则
- 新法优于旧法原则
- 法律不溯及既往原则
- 实体从旧、程序从新原则
- 程序优于实体原则

记忆逻辑：
- 上下级冲突 → 法律优位
- 普通与特别冲突 → 特别法优先
- 新旧冲突 → 新法优先
- 过去行为 → 不溯及既往
- 跨时间的实体/程序问题 → 实体从旧、程序从新
- 税收争议程序 → 程序优于实体

### 3. 税法的效力与解释
已学习：
- 时间效力
- 对人的效力
- 空间效力
- 税法解释类型：
  - 立法解释
  - 行政解释
  - 司法解释
- 解释尺度：
  - 字面解释
  - 限制解释
  - 扩充解释

重点：
- 我国税法对人的效力采用属人、属地相结合。
- 新税法代替旧税法是常见失效方式。
- 行政解释具有普遍约束力，但原则上不能作为法院判案的直接依据。

### 5. 纳税人与相关概念

## 二、税法二：企业所得税

### 1. 居民企业与非居民企业
已掌握判断逻辑：
- 依法在中国境内成立 → 居民企业
- 境外成立，但实际管理机构在中国境内 → 居民企业
- 境外成立且实际管理机构不在中国境内 → 非居民企业

### 2. 征税对象
已掌握：
- 居民企业：境内所得 + 境外所得
- 非居民企业：
  - 中国境内所得属于征税范围
  - 境外所得如与中国境内机构、场所有实际联系，也纳入中国企业所得税征税范围

### 3. 所得来源地的确定
已学习并掌握：

| 所得类型 | 来源地判断 |
|---|---|
| 销售货物所得 | 交易活动发生地 |
| 提供劳务所得 | 劳务发生地 |
| 不动产转让所得 | 不动产所在地 |
| 动产转让所得 | 转让动产的企业或机构、场所所在地 |
| 权益性投资资产转让所得 | 被投资企业所在地 |
| 股息、红利所得 | 分配所得的企业所在地 |
| 利息、租金、特许权使用费所得 | 负担、支付所得的一方所在地或住所地 |

课堂案例均能正确判断。

### 4. 企业所得税税率
已学习：
- 居民企业、以及非居民企业在境内设有机构场所且所得与该机构场所有实际联系 → 25%
- 非居民企业在境内无机构场所，或虽有机构场所但所得与其无实际联系 → 法定税率20%，实际减按10%
- 符合条件的高新技术企业等 → 15%
- 小型微利企业优惠税率 → 20%（具体减计政策后续再学）

## 四、易错点 / 重点复习点

### 1. 主动标记重点
**“税收法律关系权利义务不对等” ≠ “纳税人没有权利”**

正确理解：
- 国家享有较多权利、承担较少义务；
- 纳税人相反；
- 强调的是双方权利义务配置不对等，而非纳税人没有权利。

### 2. 实际出现过的错误
**非居民企业并非一律实际适用10%税率。**

应重点记忆：
- 境内有机构、场所 + 所得与该机构、场所有实际联系 → **25%**
- 境内无机构场所，或虽有机构场所但该笔所得与其无实际联系 → **法定20%，实际10%**

该知识点在后续结课测试中已修正并答对。

### 3. 审题失误，不作为知识错题
曾在“受托加工应税消费品代收消费税”题目中看错选项。
正确概念本身已掌握：
- 受托方向委托方收取消费税 → **代收代缴**
