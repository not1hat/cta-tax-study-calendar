## 三、税法一学习内容

### 节点1：税法运行与税务规范性文件

| 知识点 | 当日掌握内容 |
|---|---|
| 税务规范性文件定义 | 县以上税务机关依法定职权和程序制定，对不特定行政相对人反复适用 |
| 制定权限 | 县以上税务机关可以制定；内设机构、派出机构和临时机构不得以自己名义制定 |
| 禁止设定事项 | 不得设定税收开征、停征、减免退补税、行政许可、行政处罚、行政强制及行政事业性收费 |
| 发布及实施 | 应以公告形式发布；一般自发布30日后实施，符合规定的特殊情形可以立即实施 |
| 监督框架 | 规范性文件合法性审核属于事前监督，重大税务案件审理属于事中监督，执法检查及复议应诉属于事后监督 |

### 节点2：增值税特殊政策

| 知识点 | 当日掌握内容 |
|---|---|
| 资管产品 | 管理人运营资管产品发生的增值税应税行为，暂按简易计税方法适用3%征收率；运营业务与其他业务应分别核算 |
| 油气田政策 | 复习油气田企业增值税特殊征管及2026年预缴口径 |
| 黄金交易 | 复习黄金交易相关增值税现行政策，旧资料与新政策冲突时按现行官方文件执行 |
| 加油站 | 复习加油站增值税纳税人及征管特殊口径 |

### 节点3：税法一第3—12章补漏及电池消费税

| 知识点 | 当日掌握内容 |
|---|---|
| 电池消费税税率 | 2026年9月1日起，无汞原电池、金属氢化物镍蓄电池、锂原电池、锂离子蓄电池、全钒液流电池按2%征税；2027年9月1日起按4%征税 |
| 电池阶段性免税 | 2026年9月1日至2028年12月31日，钠离子电池、固态电池、燃料电池及规定的钙钛矿、叠层、砷化镓光伏电池免税 |
| 光伏电池 | 2027年4月1日起按2%，2028年4月1日起按4% |
| 电池自产自用 | 连续生产应税电池不缴税；用于其他产品或其他方面，移送使用时缴税 |
| 电池已纳税款扣除 | 外购、委托加工收回或进口的已税电池连续生产应税电池，可按规定扣除已纳税款，并建立抵扣台账 |
| 电池减免税管理 | 产品应符合国家标准，首次申报减免税前应取得符合要求的检测报告 |
| 环境保护税 | 每一排放口的应税大气污染物按污染当量数排序，对前三项征税；第一类水污染物前五项、其他类前三项 |
| 土地增值税 | 转让未经开发土地使用权，可扣除取得土地使用权支付金额及转让有关税金 |
| 关税征管 | 滞纳金按日加收0.5‰，不是0.5% |
| 社会保险费 | 灵活就业人员参加企业职工基本养老保险，缴费比例统一为20% |

## 四、税法二学习内容

### 节点1：城镇土地使用税

| 知识点 | 当日掌握内容 |
|---|---|
| 征税范围 | 城市（包括市区和郊区）、县城、建制镇和工矿区 |
| 纳税人 | 一般为土地使用权人；权利人不在所在地、权属未确定或共有时按特殊规则确定 |
| 计税公式 | 年应纳税额＝实际占用土地面积×单位税额 |
| 基本免税 | 国家机关等自用土地、公共用地、直接用于农林牧渔业的生产用地及规定期限内整治土地等 |
| 物流仓储优惠 | 符合条件的大宗商品仓储设施用地至2027年末减按50%计征 |
| 六税两费 | 小规模纳税人、小型微利企业和个体工商户至2027年末减半，可与其他优惠叠加 |
| 2026年能源资源新政 | 原有关减免土地在2026年9月1日至2027年8月31日一般减半，2027年9月1日起全额征收；新公告明确的特定用地继续免税 |
| 纳税义务发生时间 | 新建商品房交付次月；存量房证书签发次月；新征耕地满1年；新征非耕地次月 |

### 节点2：耕地占用税

| 知识点 | 当日掌握内容 |
|---|---|
| 纳税人 | 审批文件标明的建设用地人；未标明的为用地申请人；未经批准的为实际用地人 |
| 征税范围 | 占用耕地或其他农用地进行非农业建设、临时占用耕地以及损毁耕地 |
| 不征税 | 占用耕地建设农田水利设施；占用其他农用地建设直接服务农业生产的生产设施 |
| 计税公式 | 应纳税额＝实际占用应税面积×适用税额，一次性征收 |
| 基本农田 | 按当地适用税额乘以150%，不是增加150%后乘以250% |
| 交通设施优惠 | 铁路、公路线路等减按2元/平方米；专用铁路、铁路专用线、专用公路及城区机动车道按当地税额征税 |
| 征收管理 | 纳税义务发生后30日内在耕地所在地申报 |
| 复垦退税 | 临时占地期满后1年内复垦可全额退税；损毁耕地在认定后3年内复垦或修复可申请退税 |

### 节点3：船舶吨税

| 知识点 | 当日掌握内容 |
|---|---|
| 征税范围及纳税人 | 从境外港口进入境内港口的船舶；纳税人为应税船舶负责人 |
| 税率 | 中国籍及符合相互给予船舶税费最惠国待遇条件的船舶适用优惠税率，其他船舶适用普通税率 |
| 计算公式 | 应纳税额＝船舶净吨位×定额税率 |
| 拖船 | 每千瓦折合0.67净吨，并按相同净吨位船舶税率的50%计税 |
| 无净吨位证明的游艇 | 每千瓦折合0.05净吨 |
| 非机动船舶与驳船 | 非机动船舶免税，但非机动驳船不免税，按50%计税 |
| 纳税管理 | 进入港口当日发生纳税义务；海关征收；缴款凭证填发后15日内缴税；滞纳金0.5‰/日 |
| 追补退税 | 一般少征1年内补征；违法造成少征3年内追征并加收滞纳金；船舶发现多缴可在3年内申请退税 |
