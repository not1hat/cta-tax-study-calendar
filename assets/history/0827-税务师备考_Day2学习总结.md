# 税务师备考 Day 2 学习总结

> 用途：同步给另一个聊天框，说明 Day 2 已完成的学习内容、掌握情况、薄弱点和后续复习重点。

## 一、Day 2 学习主题

### 税法一：增值税——纳税人＋征税范围

已学习并练习以下内容：

#### 1. 应税交易基本分类
- 销售货物
- 销售服务
- 销售无形资产
- 销售不动产

已能区分常见业务类型，例如：
- 打印机销售 → 货物
- 专利技术使用权转让/出租 → 无形资产
- 运输 → 服务
- 写字楼销售 → 不动产
- 网络游戏虚拟道具 → 无形资产

#### 2. 境内应税交易判断
已掌握基本判断逻辑：
- 服务、无形资产是否在境内消费
- 销售方是否为境内单位或个人
- 境外现场消费服务不属于境内应税交易

已练习案例：
- 日本公司向中国公司提供在中国境内消费的咨询服务 → 属于境内应税交易
- 中国公司员工赴日本住宿，日本酒店提供住宿服务 → 不属于境内应税交易
- 日本律师事务所处理日本诉讼、服务在境外现场消费 → 不属于境内应税交易

#### 3. 视同应税交易与不属于应税交易
已掌握：
- 自产/委托加工货物用于集体福利、个人消费 → 视同应税交易
- 外购货物用于集体福利、个人消费 → 不视同应税交易
- 员工为本单位提供取得工资薪金的服务 → 不属于应税交易
- 存款利息 → 不属于应税交易
- 征收征用补偿等特定项目 → 不属于应税交易

特别修正：
- 按 2026 资料口径，无偿提供服务不再直接按旧口径理解为“视同应税交易”。
- 企业无偿借款、不收利息 → 不征收增值税，但不宜表述为“存款利息式的不属于应税交易”。

#### 4. 混合销售与兼营
已掌握判断核心：
- 同一项交易中货物＋服务，有明显主从关系 → 混合销售
- 不同业务相互独立 → 兼营
- 混合销售按主要业务适用税率

已练习：
- 家具销售＋安装 → 混合销售
- 商品零售＋独立咨询 → 兼营
- 建筑工程＋工程所需材料 → 混合销售

#### 5. 交通运输服务特殊项目
已掌握：
- 程租、期租 → 水路运输服务
- 湿租 → 航空运输服务
- 光租、干租 → 有形动产经营租赁服务
- 无运输工具承运业务 → 交通运输服务
- 出租车公司向使用本公司自有出租车的司机收取管理费 → 陆路运输服务

术语需注意：
- 船舶不配船员 → 光租
- 飞机不配机组人员 → 干租

#### 6. 邮政、电信、建筑服务
已掌握高频分类：
- 手机语音通话 → 基础电信服务
- 互联网接入 → 增值电信服务
- 有线电视初装费 → 建筑服务—安装服务
- 建筑物修补、加固 → 修缮服务
- 装修、美化、形成特定用途 → 装饰服务

#### 7. 金融服务
已学习四大分类：
- 贷款服务
- 直接收费金融服务
- 保险服务
- 金融商品转让

已掌握：
- 企业之间借款收利息/资金占用费 → 贷款服务
- 保本理财收益、固定利润、保底利润 → 贷款服务
- 账户管理费、结算手续费等 → 直接收费金融服务
- 股票等金融商品卖出取得价差 → 金融商品转让
- 金融商品持有期间取得非保本收益 → 不征收增值税
- 银行存款利息 → 不属于应税交易

**本部分为当前薄弱点之一，需要后续继续回测。**

最重要的三分法：
- 借款收利息/资金占用费 → 贷款服务
- 非保本金融商品持有收益 → 不征收增值税
- 存款利息 → 不属于应税交易

#### 8. 现代服务——租赁服务
已掌握：
- 商场外墙广告位出租 → 不动产经营租赁服务
- 公交车车身广告位出租 → 有形动产经营租赁服务
- 停车服务 → 不动产经营租赁服务
- 干租飞机 → 有形动产经营租赁服务
- 融资性售后回租 → 金融服务—贷款服务

#### 9. 现代服务——鉴证咨询与商务辅助
已掌握：
- 税务咨询 → 鉴证咨询服务—咨询服务
- 税务鉴证、审计鉴证 → 鉴证咨询服务—鉴证服务
- 代理记账、房产中介 → 商务辅助服务—经纪代理服务
- 招聘 → 商务辅助服务—人力资源服务

#### 10. 一般纳税人与小规模纳税人
已掌握：
- 年应税销售额 500 万元为重要分界
- ≤500 万元：原则上小规模，但会计核算健全、能提供准确税务资料的，可登记为一般纳税人
- ＞500 万元：原则上应办理一般纳税人登记
- 自然人即使超过 500 万元，仍按小规模纳税人纳税
- 特定非企业单位可选择按小规模纳税人纳税
- 年应税销售额看连续不超过 12 个月或 4 个季度
- 偶然发生的销售无形资产、转让不动产销售额不计入 500 万元判断口径
- 一般纳税人登记后原则上不得转回小规模纳税人

#### 11. 境外单位增值税扣缴
已掌握判断顺序：
1. 先判断是否属于境内应税交易
2. 若境外销售方在境内无经营机构
3. 再判断境内购买方是否承担扣缴义务

案例：
- 日本公司无境内经营机构，向中国公司提供境内消费的咨询服务 → 中国购买方为扣缴义务人
- 日本酒店向赴日员工提供住宿 → 不属于境内应税交易，因此中国公司无需扣缴

### 税法二：企业所得税——收入总额框架

已学习并练习以下内容：

#### 1. 收入总额基本分类
包括：
- 销售货物收入
- 提供劳务收入
- 转让财产收入
- 股息、红利等权益性投资收益
- 利息收入
- 租金收入
- 特许权使用费收入
- 接受捐赠收入
- 其他收入

#### 2. 销售货物收入确认时间
已掌握：
- 分期收款 → 按合同约定的收款日期分别确认
- 托收承付 → 办妥托收手续时
- 预收款 → 发出商品时
- 需要安装和检验 → 原则上购买方接受商品并安装检验完毕时；安装简单可在发货时确认
- 委托代销 → 收到代销清单时

**当前易错点：**
- 分期收款不是按“实际收款日”确认，而是按“合同约定收款日”确认。

#### 3. 特殊销售方式下收入金额
已掌握：
- 商业折扣 → 按扣除商业折扣后的金额确认收入
- 现金折扣 → 按扣除现金折扣前的金额确认收入，现金折扣实际发生时计入财务费用
- 买一赠一 → 不属于捐赠，按各商品公允价值比例分摊总销售额
- 以旧换新 → 新商品按正常销售确认收入，旧商品作为购进处理
- 售后回购 → 原则上销售按售价确认、回购作为购进；实质融资时按融资处理

#### 4. 提供劳务收入
已掌握：
- 跨年且持续超过 12 个月的劳务 → 按完工进度或完成工作量确认
- 安装费 → 原则上按安装完工进度确认
- 广告制作费 → 按完工进度确认
- 宣传媒介收费 → 广告或商业行为出现在公众面前时确认
- 特定客户软件开发 → 按完工进度确认
- 特殊活动收费 → 活动发生时确认
- 只有会籍、其他商品服务另收费的会员费 → 取得会员费时一次确认
- 会员费对应未来一段期间实际服务权益 → 在受益期内分期确认

**当前易错点：**
- 广告制作费 → 完工进度
- 宣传媒介收费 → 广告出现在公众面前时
这两个容易混淆，已连续出现过错误，需要隔夜回测。

#### 5. 转让财产收入
重点掌握股权转让：
- 股权转让收入确认时点 → 转让协议生效且完成股权变更手续时
- 股权转让所得 = 转让收入 - 股权成本
- 计算股权转让所得时，不得扣除被投资企业未分配利润等留存收益中按持股比例可能分配的金额

#### 6. 股息、红利等权益性投资收益
已掌握：
- 按被投资企业股东会/股东大会作出利润分配或转股决定的日期确认收入
- 不按实际收到股息的日期确认

清算所得：
- 对应累计未分配利润和累计盈余公积的部分 → 先确认为股息所得
- 其余部分再与投资成本比较，确认投资转让所得或损失

#### 7. 利息、租金、特许权使用费
已掌握：
- 利息收入 → 按合同约定的债务人应付利息日期确认
- 租金收入 → 按合同约定的承租人应付租金日期确认
- 跨年度且租金提前一次性支付 → 可在租赁期内分期均匀确认
- 特许权使用费收入 → 按合同约定的应付日期确认

#### 8. 接受捐赠收入
已掌握：
- 按实际收到捐赠资产的日期确认收入
- 货币性捐赠按实际收到金额确认
- 非货币性资产按相应规定确认金额

#### 9. 其他收入
已识别的典型项目：
- 资产溢余收入
- 逾期未退包装物押金
- 确实无法偿付的应付款
- 坏账损失处理后又收回的应收款
- 债务重组收入
- 补贴收入
- 违约金收入
- 汇兑收益等

#### 10. 政府财政资金
已掌握：
- 按销售货物/提供劳务数量、金额的一定比例给予的政府资金 → 按权责发生制确认
- 其他普通财政补贴、补助、补偿、退税等 → 实际取得时确认
