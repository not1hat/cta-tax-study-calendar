## 二、今日核心知识

### （一）税法一：增值税征收管理

1. 正常应税交易：收讫销售款项或取得索取款项凭据日；提前开票按开票日。
2. 无书面合同或未约定付款日：按交易完成日，即货物发出、服务完成、金融商品所有权转移、无形资产或不动产转让完成日。
3. 视同应税交易：完成视同交易当日；进口货物：报关进口当日；出口报关日在先时按报关出口日。
4. 有固定经营场所：机构所在地或居住地；无固定场所：交易发生地；进口：海关规定地点。
5. 自然人销售或租赁不动产、转让自然资源使用权、提供建筑服务：按标的所在地或服务发生地。
6. 境外单位个人发生境内应税交易：原则由购买方扣缴；按规定委托境内代理人申报的除外。
7. 扣缴税额＝不含税销售额×税率；扣缴时间与境外纳税人纳税义务发生时间一致。
8. 预缴税款与正式纳税义务发生不是同一概念。

### （二）税法二：企业所得税扣除与亏损

1. 投资撤回三段法：投资收回＋股息所得＋投资资产转让所得。
2. 投资资产转让所得＝取得资产－对应初始投资－按减资比例计算的未分配利润和盈余公积。
3. 被投资企业经营亏损由其自行弥补，投资企业不得调低投资成本或直接确认投资损失。
4. 普通企业自行计提的未经核定准备金不得扣除；实际或法定资产损失符合条件时可以扣除。
5. 普通汇兑损失、合理劳动保护费、财产保险费可按规定扣除；资本化汇兑损失随资产扣除。
6. 经营租赁费按租期均匀扣除；融资租赁费计入资产，通过折旧扣除。
7. 开办费可在开始经营当年一次扣除或按长期待摊处理，一经选择不得改变。
8. 不得扣除：股息红利、企业所得税、税收滞纳金、行政罚款罚金、不合规捐赠、非广告赞助、未经核定准备金、无关支出。
9. 银行逾期罚息、经营合同违约金与行政罚款不同，符合相关合理条件时可以扣除。
10. 一般企业税法亏损结转5年；符合条件的高新技术企业、科技型中小企业等最长10年；多年度亏损先弥补最早到期年度。

## 五、不得抵扣进项的修复结论

| 情形 | 处理 |
|---|---|
| 贷款利息对应进项 | 暂不得抵扣 |
| 支付给贷款方且与贷款直接相关的顾问费、手续费、咨询费进项 | 暂不得抵扣 |
| 独立第三方提供的普通经营咨询服务 | 符合一般条件时可抵扣 |
| 正常一般计税生产设备 | 符合条件时可抵扣 |
| 外购货物购入时已确定用于职工福利 | 不视同交易；直接不得抵扣 |
| 外购货物原已抵扣后转作职工福利 | 不视同交易；进项转出 |
| 自产或委托加工货物用于职工福利 | 视同应税交易；相关进项按一般规则处理 |
