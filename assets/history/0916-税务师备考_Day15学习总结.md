## 二、税法（一）学习内容

### 节点1：城建税纳税人、范围与税率

| 知识点 | 结论 |
|---|---|
| 纳税人 | 在境内缴纳增值税、消费税的单位和个人 |
| 基本税率 | 市区7%；县城、镇5%；其他地区1% |
| 跨地区预缴 | 按增值税预缴所在地的城建税税率计算 |
| 代扣代缴 | 按代扣代缴“两税”所在地适用税率 |
| 行政区划变化 | 行政区划变更完成当月起适用新税率 |
| 进口例外 | 进口环节增值税、消费税不征城建税 |

### 节点2：计税依据与“两税”联动

| 项目 | 城建税计税依据处理 |
|---|---|
| 实际缴纳及查补的增值税、消费税 | 计入 |
| “两税”滞纳金、罚款 | 不计入 |
| 直接减免的“两税” | 不计入 |
| 进口环节“两税” | 不计入 |
| 经审核批准的生产企业出口免抵税额 | 计入 |
| 符合规定的增值税期末留抵退税额 | 从计税依据中扣除 |
| 出口退还“两税” | 已缴城建税一般不退 |
| 先征后返、先征后退、即征即退 | 城建税一般不退返 |

计算案例：市区企业境内实缴增值税40万元、进口增值税15万元，可扣除留抵退税额5万元，无消费税：

`应纳城建税＝（40－5）×7%＝2.45万元`

### 节点3：优惠、征管及两项附加

| 知识点 | 结论 |
|---|---|
| 减半政策 | 2023—2027年，符合条件的小规模纳税人、小型微利企业、个体工商户减半征收城建税和两项附加 |
| 征管跟随 | 城建税纳税时间、期限、地点和扣缴原则跟随增值税、消费税 |
| 教育费附加 | 实缴“两税”×3% |
| 地方教育附加 | 实缴“两税”×2% |
| 附加进口规则 | 海关代征的进口“两税”不征两项附加 |
| 附加小额免征 | 按月销售额或营业额不超过10万元、按季不超过30万元，符合条件时免征两项附加 |

综合案例：市区个体工商户实缴增值税8万元，符合减半政策且不适用小额免征：

- 城建税：`8×7%×50%＝0.28万元`；
- 教育费附加：`8×3%×50%＝0.12万元`；
- 地方教育附加：`8×2%×50%＝0.08万元`；
- 合计：`0.48万元`。

## 三、税法（二）学习内容

### 节点1：企业所得税应纳税额与境外抵免

企业所得税完整公式：

`应纳税额＝境内外应纳税所得总额×税率－减免税额－抵免税额－允许抵免的境外所得税额`

| 项目 | 规则 |
|---|---|
| 直接抵免 | 境外营业利润税、股息利息租金许可费等直接缴纳或源泉扣缴税款 |
| 间接抵免 | 符合条件的境外子公司分红前利润所负担的境外所得税 |
| 抵免限额 | 境外应纳税所得额×我国适用税率 |
| 本期允许抵免 | 境外实缴税额与抵免限额取较小数 |
| 超限额部分 | 以后5个年度内结转抵免 |
| 间接抵免持股 | 直接或间接持股20%以上，最多五层，各单一持股符合20%要求 |

直接抵免案例：境内所得800万元、境外税前所得200万元、境外实缴60万元、我国税率25%：

- 抵免限额：`200×25%＝50万元`；
- 本期抵免50万元；
- 我国应纳税额：`（800＋200）×25%－50＝200万元`；
- 超限额10万元以后5个年度内按规定结转。

间接抵免案例：境外子公司税前利润100万元、企业所得税20万元、分红预提税8万元，中国企业实际收到72万元：

- 还原税前所得：`72＋8＋20＝100万元`；
- 可抵免境外税额：`8＋20＝28万元`；
- 抵免限额：`100×25%＝25万元`；
- 本期允许抵免25万元。

### 节点2：关联申报、同期资料和转让定价

| 知识点 | 关键标准 |
|---|---|
| 股权关联 | 直接或间接持股达到25%；第三方对双方持股均达到25% |
| 资金借贷关联 | 借贷资金占实收资本达到50%；符合条件的担保比例达到10% |
| 主体文档 | 跨境关联交易且集团已准备主体文档，或年度关联交易总额超过10亿元 |
| 本地文档 | 有形资产超过2亿元；金融资产超过1亿元；无形资产超过1亿元；其他关联交易超过4,000万元 |
| 特殊事项文档 | 成本分摊协议、资本弱化 |
| 准备期限 | 主体文档年度终了12个月内；本地及特殊事项文档次年6月30日前 |
| 提供、保存 | 一般自税务机关要求之日起30日内提供；保存10年 |

转让定价方法：可比非受控价格法、再销售价格法、成本加成法、交易净利润法、利润分割法。

再销售价格法案例：独立客户售价1,000万元、可比毛利率20%：

`公平成交价格＝1,000×（1－20%）＝800万元`

预约定价安排采用四分位法；实际经营结果在四分位区间外时，税务机关可以调整至区间中位值。

### 节点3：资本弱化、受控外国企业、一般反避税和源泉扣缴

| 制度 | 关键内容 |
|---|---|
| 资本弱化 | 标准关联债资比：金融企业5∶1、其他企业2∶1 |
| 不得扣除利息 | 实际关联利息×（1－标准比例÷实际关联债资比例） |
| 受控外国企业 | 无合理经营需要将利润留存在低税负受控外国企业，可能视同分配 |
| CFC免予视同分配 | 指定非低税地区、主要为积极经营所得、年度利润低于500万元 |
| 一般反避税 | 获取税收利益为主要目的，形式合规但与经济实质不符 |
| 一般反避税方法 | 重新定性、否定主体、视为同一实体、重新分配所得扣除抵免等 |
| 非居民源泉扣缴 | 未设机构场所或所得与所设机构场所无实际联系，通常适用10%，协定优先 |
| 股息利息租金许可费 | 以收入全额为应纳税所得额 |
| 财产转让 | 转让收入减财产净值后的余额为应纳税所得额 |

资本弱化案例：非金融企业实际关联债资比4∶1、关联利息100万元：

`不得扣除利息＝100×（1－2÷4）＝50万元`

源泉扣缴案例：非居民企业转让境内财产，收入1,000万元、财产净值600万元：

`应扣缴企业所得税＝（1,000－600）×10%＝40万元`
