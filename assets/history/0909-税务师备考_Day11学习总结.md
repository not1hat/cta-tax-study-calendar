## 四、税法（一）学习内容

### 节点1：纳税人和基本征税环节

- 在中国境内生产、委托加工和进口应税消费品的单位和个人，为消费税纳税人。
- 消费税一般在生产销售、委托加工和进口环节征收。
- 委托加工要求委托方提供原材料，受托方只收取加工费和代垫部分辅助材料。
- 受托方提供主要原材料的，不按消费税委托加工处理，应按受托方销售自产应税消费品处理。

节点测试：5题，正确5题，正确率100%。

### 节点2：消费税税目

- 重点掌握烟、酒、高档化妆品、贵重首饰及珠宝玉石、鞭炮焰火、成品油、摩托车、小汽车、高尔夫球及球具、高档手表、游艇、木制一次性筷子、实木地板、电池、涂料。
- 区分应税消费品与普通消费品，例如普通护肤品不属于高档化妆品税目。

节点测试：8题，正确8题，正确率100%。

### 节点3：计税方法和特殊征税环节

| 内容 | 核心规则 |
|---|---|
| 从价定率 | 应纳税额＝销售额×比例税率 |
| 从量定额 | 应纳税额＝销售数量×单位税额 |
| 复合计税 | 应纳税额＝销售额×比例税率＋销售数量×单位税额 |
| 从量定额典型项目 | 黄酒、啤酒、成品油 |
| 复合计税典型项目 | 卷烟、白酒 |
| 卷烟批发 | 批发企业销售给零售企业加征；批发企业之间销售不缴批发环节消费税 |
| 零售环节 | 金银首饰、铂金首饰、钻石及钻石饰品等在零售环节征税 |
| 超豪华小汽车 | 在规定的零售环节加征消费税 |

节点测试：8题，正确7题，正确率87.5%。

错题：第8题漏选“卷烟批发企业销售给另一卷烟批发企业不缴纳批发环节消费税”。

## 五、税法（二）学习内容

### 节点1：居民个人与非居民个人

| 类型 | 判定 | 纳税义务 |
|---|---|---|
| 居民个人 | 境内有住所；或者无住所但一个纳税年度内累计居住满183天 | 原则上就境内、境外所得纳税 |
| 非居民个人 | 境内无住所又不居住；或者无住所且累计居住不满183天 | 原则上仅就境内来源所得纳税 |

- 境内有住所，是指因户籍、家庭、经济利益关系而在境内习惯性居住。
- 无住所个人在境内停留的当天满24小时才计入居住天数；不足24小时不计入。
- 身份居住天数与跨境工资分摊中的工作天数不能混淆。

节点测试：6题，正确6题，正确率100%。

### 节点2：所得来源地

| 所得类型 | 来源地判断标准 |
|---|---|
| 任职、受雇、履约等劳务 | 劳务实际发生地 |
| 财产租赁 | 财产实际使用地 |
| 特许权使用费 | 特许权实际使用地 |
| 不动产转让 | 不动产所在地 |
| 其他财产转让 | 转让行为发生地；权益性投资资产重点看被投资企业所在地 |
| 利息、股息、红利 | 支付方所在地 |

- 所得来源地原则上不以款项支付地点、收款账户所在地作为判断标准。
- 应依次判断所得来源地、居民身份，再判断免税规定或税收协定待遇。

节点测试：6题，正确6题，正确率100%。

### 节点3：九项所得和税率

| 类别 | 所得项目 | 计税方式或税率 |
|---|---|---|
| 综合所得 | 工资薪金、劳务报酬、稿酬、特许权使用费 | 居民个人按年合并；3%—45%超额累进税率 |
| 经营所得 | 经营所得 | 5%—35%超额累进税率 |
| 分类所得 | 利息股息红利、财产租赁、财产转让、偶然所得 | 分别计算，一般适用20%比例税率 |

重点辨析：

- 因任职、受雇取得的收入属于工资、薪金所得；独立从事非雇佣劳务属于劳务报酬所得。
- 雇员兼任董事取得董事费属于工资薪金；独立董事费属于劳务报酬。
- 本单位记者、编辑在本单位报刊发表作品取得收入属于工资薪金。
- 作品以图书、报刊形式出版、发表取得收入属于稿酬；许可著作权使用取得收入属于特许权使用费。

节点测试：8题，正确6题，正确率75%。

错题：

1. 第4题漏选“本单位记者在本单位报纸发表作品取得的收入属于工资薪金所得”。
2. 第6题将图书出版收入误判为特许权使用费；正确项目为稿酬所得。

## 六、计算案例

### 1. 从价计征消费税

高档化妆品不含增值税销售额200,000元，税率15%：

应纳消费税＝200,000×15%＝30,000元。

### 2. 委托加工组成计税价格

材料成本60,000元，加工费20,000元，比例税率10%，受托方无同类销售价格：

组成计税价格＝（60,000＋20,000）÷（1－10%）＝88,888.89元。

应代收代缴消费税＝88,888.89×10%＝8,888.89元。

### 3. 财产转让所得个人所得税

取得转让收入500,000元，财产原值320,000元，合理费用20,000元：

应纳税所得额＝500,000－320,000－20,000＝160,000元。

应纳个人所得税＝160,000×20%＝32,000元。
