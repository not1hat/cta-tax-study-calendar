## 三、税法一学习内容

### 节点1：进口货物海关估价顺序

| 知识点 | 核心内容 |
|---|---|
| 成交价格适用条件 | 使用处置原则上不受限制；价格能够确定；卖方无不能调整的进口后收益；特殊关系未影响价格 |
| 估价顺序 | 相同货物→类似货物→再销售价格→成本加成→合理方法 |
| 顺序调整 | 纳税人提供资料并申请，可以调整再销售价格法与成本加成法的顺序 |
| 再销售价格法 | 境内第一级销售环节、无特殊关系买方、最大销售总量的单位价格，再扣除规定项目 |
| 成本加成法 | 料件和加工成本＋通常利润和一般费用＋起卸前运保费 |

节点检测：4/5，80%。

### 节点2：特殊进出口货物计税价格

| 知识点 | 核心内容 |
|---|---|
| 境外修理 | 修理费＋料件费，不计复运进境运保费 |
| 境外加工 | 加工费＋料件费＋复运进境运费及保险费 |
| 暂时进境留购 | 海关确定的留购价格 |
| 租赁进口 | 分期租金包含利息；期满留购按留购价格；一次性缴税可按一般估价或租金总额 |
| 减免税货物转让 | 原进口计税价格×〔1－已进口月数÷（监管年限×12）〕 |
| 软件介质 | 符合分列或举证条件时，以介质本身价值或成本为基础 |
| 公式定价 | 价格取决于双方无法控制的客观因素；通常6个月确定，经批准可延长到9个月 |
| 跨境电商 | 计税价格包括零售价、运费和保险费；限值内关税为0，进口增值税、消费税按法定税额70%征收 |

节点检测：5/6，83.33%。

### 节点3：关税价格换算与计算

| 知识点 | 公式或规则 |
|---|---|
| CIF | 已含货价、国际运费和保险费 |
| FOB转CIF | FOB＋国际运费＋保险费 |
| CFR转CIF | CFR＋保险费 |
| 保险费无法确定 | （货价＋运费）×3‰ |
| 从价计征 | 计税价格×比例税率 |
| 从量计征 | 数量×单位定额税额 |
| 复合计征 | 计税价格×比例税率＋数量×单位定额税额 |
| 含出口关税价格 | 出口计税价格＝含税成交价格÷（1＋出口税率） |

节点检测：4/5，80%。

## 四、税法二学习内容

### 节点1：税收情报交换与CRS

| 知识点 | 核心内容 |
|---|---|
| 情报交换形式 | 专项、自动、自发、同期税务检查、授权代表访问、行业范围情报交换 |
| CRS作用 | 识别账户持有人或控制人的税收居民身份，识别、收集、报送并自动交换非居民金融账户信息 |
| 消极非金融机构 | 消极收入占比50%以上，或相关金融资产占比50%以上，或居民国不实施自动交换标准的投资机构 |
| 排除主体 | 上市公司、政府及公共服务机构、符合条件的控股公司、新设未经营企业、清算重组企业、集团内部融资企业、非营利组织等 |
| 无需调查账户 | 符合条件的退休金、社会保障以及法院裁判、不动产交易、抵押预留税款保险费、专门支付税款等账户 |

节点检测：5/5，100%。

### 节点2：BEPS与经济数字化国际税收

| 知识点 | 核心内容 |
|---|---|
| 支柱一 | 解决市场辖区征税权分配，包含金额A和金额B |
| 金额A | 年合并收入超过200亿欧元且税前利润率超过10%；排除采掘业和受监管金融服务业 |
| 金额B | 为基础营销和分销活动提供简化转让定价方法 |
| 支柱二 | 通过GloBE和应税规则抑制税基侵蚀和逐底竞争 |
| GloBE | 全球最低有效税率15%；收入纳入规则优先于低税支付规则 |
| 应税规则 | 教材名义税率底线9% |
| ADS | 通过网络提供、只需最少量人工参与；在线广告、云计算和标准化在线教学等通常属于ADS |

节点检测：5/5，100%。

### 节点3：国际税收全章串联

综合答题顺序：

1. 判断居民身份和所得来源；
2. 依据国内法形成初步纳税义务；
3. 依据税收协定限制或分配征税权；
4. 确定自行申报、源泉扣缴或核定征收；
5. 计算境外税收抵免，并检查一般反避税、BEPS、CRS及情报交换。

重点结论：

- 税收协定不能扩大国内税法原本不存在的征税权；
- 来源国通常仅对归属于常设机构的营业利润征税；
- 境外实际抵免额为境外已纳税额与抵免限额中的较小者；
- 收入法核定企业所得税时，应先计算应纳税所得额，再乘25%税率。

节点检测：4/5，80%。

税法二节点检测合计：14/15，93.33%。
