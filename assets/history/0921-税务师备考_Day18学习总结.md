## 二、当日学习内容与计算案例

| 节点 | 核心结论与课堂计算 |
|---|---|
| 税一① | 税目涉及能源、金属、非金属、水气矿产和盐；自采原矿销售按原矿口径，自采原矿洗选为选矿后销售按选矿口径；不同税目或税率须分别核算。 |
| 税一② | 从价税基为不含增值税销售额，符合条件且有合法有效凭据的运杂费可扣。例：销售额100万元含合规运杂5万元、税率5%，税额`(100－5)×5%=4.75万元`。无可比价时，组成计税价格=`成本×(1＋成本利润率)÷(1－资源税税率)`。 |
| 税一③ | 外购原矿与自采原矿混合为原矿销售可直接扣购进额；混合洗选成选矿销售的扣减额=`外购原矿购进额×原矿税率÷选矿税率`。例：选矿销售500万元、合规运杂20万元、外购原矿150万元、原矿4%、选矿5%，税额=`[500－20－150×4%÷5%]×5%=18万元`。另例同类原矿销售300万元、外购100万元、税率4%，税额8万元。 |
| 税二① | 无住所者当年境内累计居住满183天为居民个人；不足24小时的当天不计居住天数，特定任职情形的工作天数按半天。普通员工月工资6万元，境内支付50%、境内工作12/30天：≤90天为1.2万元；＞90天＜183天为2.4万元；满183天且符合此前六年免税条件，若境外支付40%、境外工作18/30天，为4.56万元。以上为工资薪金**收入额**，非最终税额。 |
| 税二② | 非居民工资薪金应纳税所得额=`月收入额－5000元`；劳务、特许权使用费为每次收入×80%；稿酬再×70%，例1万元稿酬应纳税所得额5600元。高管≤90天的境内雇主支付额不乘工作天数；工资6万元、境内支付2万元，则收入额2万元。＞90天＜183天，境外支付4万元、境外工作18/30天，则收入额`6万－4万×18/30=3.6万元`。数月奖金单独按6个月分摊且一年仅适用一次；股权激励本年累计后扣已缴税。 |
| 税二③ | 抵免按来源国（地区）分别计算，限额为该国综合、经营、其他分类所得限额之和；当年抵免取合格实际已缴税与限额较小者。例：甲国限额2000元、已缴2500元，抵2000元、超500元可按规定以后5个纳税年度结转；乙国限额2000元、已缴1000元，抵1000元；合计3000元，甲国超额不挪至乙国。甲国经营亏损不得抵境内或乙国所得，可用甲国以后年度经营所得按中国税法弥补。申报期为次年3月1日至6月30日。 |

### 结尾第4题详解

个人所得税居民身份先看是否在中国境内有住所；无住所者再看本纳税年度境内居住累计天数。**不满183天**为非居民，**满183天（包括恰好183天）**为居民。六年规则只影响特定境外所得的征免范围，不会把已满183天的个人重新判成非居民。下次复测宜并列比较“182天、183天、此前六年”三个判断层次。
