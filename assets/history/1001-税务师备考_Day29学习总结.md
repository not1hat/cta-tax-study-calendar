## 三、税法一学习内容

### 节点1：税法原则与效力

#### 1. 税法基本原则

| 记忆字 | 原则 | 核心判断词 |
|---|---|---|
| 定 | 税收法律主义 | 课税要素法定、明确、依法稽征 |
| 公 | 税收公平主义 | 按负担能力公平分配税负 |
| 信 | 税收合作信赖主义 | 正式表示、值得保护、依此行动 |
| 实 | 实质课税原则 | 真实负担能力、经济实质 |

#### 2. 税法适用原则

| 冲突场景 | 适用原则 | 结论 |
|---|---|---|
| 法律层级不同 | 法律优位 | 法律高于法规，法规高于规章 |
| 特别规定与一般规定冲突 | 特别法优于普通法 | 具体事项优先适用特别规定 |
| 同一机关的新旧规定冲突 | 新法优于旧法 | 原则上适用已生效的新规定 |
| 新法能否处理生效前行为 | 法律不溯及既往 | 原则上不得追溯 |
| 旧行为在新法后进入征收程序 | 实体从旧、程序从新 | 实体义务按旧法，程序原则上按新法 |
| 已进入复议或诉讼程序 | 程序优于实体 | 先满足程序要求，再处理实体争议 |

重点辨析：法律优位看“效力层级”；特别法优先看“特别规定与一般规定”；新法优先解决新旧规定冲突；不溯及既往保护新法生效前已发生的行为。

### 节点2：增值税征税范围

| 知识框架 | 当日学习内容 |
|---|---|
| 基本范围 | 销售货物、加工修理修配劳务、服务、无形资产和不动产 |
| 服务分类 | 交通运输、邮政、电信、建筑、金融、现代服务及生活服务等 |
| 境内交易 | 结合销售方、购买方、消费地、使用地及不动产所在地判断 |
| 视同应税交易 | 单位无偿转让货物、无形资产、不动产及金融商品等规定情形 |
| 外购货物用于福利 | 不属于视同应税交易，通常属于进项税额不得抵扣情形 |
| 公益无偿服务 | 符合规定的公益事业或面向社会公众的无偿服务不按视同交易处理 |
| 非应税事项 | 员工受雇服务、存款利息、依法征收征用补偿、符合条件的资产重组等 |
| 特殊服务税目 | 运输逾期票证、武装守护押运、会议场地及配套服务、餐饮附带酒水等 |

核心记忆：**自产或委托加工货物用于集体福利，按视同；外购货物用于集体福利，不视同，但进项不得抵扣。**

### 节点3：增值税纳税人、税率与征收率

| 知识点 | 当日学习内容 |
|---|---|
| 纳税人 | 在境内发生增值税应税交易的单位和个人 |
| 扣缴义务 | 境外单位或个人在境内发生应税交易且境内无经营机构时，按规定判断扣缴义务人 |
| 一般纳税人标准 | 年应征增值税销售额通常以500万元为登记判断标准 |
| 小规模纳税人 | 按简易计税方法及适用征收率计算，不抵扣进项税额 |
| 13%税率 | 一般货物、加工修理修配、有形动产租赁等 |
| 9%税率 | 农产品等规定货物、交通运输、邮政、基础电信、建筑、不动产及土地使用权等 |
| 6%税率 | 金融服务、现代服务、生活服务及增值电信服务等 |
| 零税率 | 符合条件的出口货物、国际运输、航天运输和跨境服务等 |
| 征收率 | 简易计税使用征收率；注意3%、适用减征口径及旧货政策 |

当日计算训练包括13%税率、6%税率、简易计税征收率以及同一纳税人发生多项交易时的分类计算。

## 四、税法二学习内容

### 节点1：企业所得税纳税人、所得来源地与税率

#### 1. 纳税人与纳税义务

| 类型 | 判定及纳税范围 |
|---|---|
| 居民企业 | 依法在中国境内成立，或依外国法律成立但实际管理机构在境内；就境内外所得纳税 |
| 非居民企业 | 依外国法律成立且实际管理机构不在境内；按境内机构、场所以及所得联系确定纳税范围 |
| 不属于企业所得税纳税人 | 个人独资企业、合伙企业中的自然人层面及居民个人等按个人所得税规则处理 |

#### 2. 所得来源地

| 所得类型 | 来源地判断标准 |
|---|---|
| 销售货物 | 交易活动发生地 |
| 提供劳务 | 劳务发生地 |
| 不动产转让 | 不动产所在地 |
| 动产转让 | 转让动产的企业或机构、场所所在地 |
| 权益性投资资产转让 | 被投资企业所在地 |
| 股息、红利 | 分配所得的企业所在地 |
| 利息、租金、特许权使用费 | 负担或支付所得的企业、机构、场所所在地，或个人住所地 |

#### 3. 税率框架

| 情形 | 税率口径 |
|---|---:|
| 居民企业基本税率 | 25% |
| 符合条件的小型微利企业法定税率 | 20%，实际税负按现行优惠政策处理 |
| 国家重点扶持的高新技术企业 | 15% |
| 符合条件的非居民企业境内所得 | 法定税率20%，符合条件时实际按10%征收 |

计算训练：居民企业按25%、高新技术企业按15%、符合条件的非居民企业预提所得税按实际适用口径计算。

### 节点2：企业所得税收入确认

| 模块 | 当日学习内容 |
|---|---|
| 收入总额 | 货币形式及非货币形式收入；非货币收入按公允价值确定 |
| 销售货物 | 结合销售方式、交付、收款或取得索款凭据等条件确认收入 |
| 商业折扣 | 按扣除商业折扣后的金额确认销售收入 |
| 销售折让及退回 | 按规定冲减当期销售收入 |
| 买一赠一 | 不按捐赠处理，将总销售金额按各项商品公允价值比例分摊 |
| 产品分成 | 按分得产品日期确认，收入额按产品公允价值确定 |
| 长期劳务 | 符合条件时按纳税年度内完工进度或完成工作量确认收入 |
| 利息、租金等 | 分别按合同约定的应付日期或法定确认时点确认 |
| 内部处置 | 资产所有权未发生转移，一般不视同销售 |
| 外部处置 | 资产所有权转移，用于市场推广、职工福利、对外捐赠等通常视同销售 |

当日完成买一赠一分摊、完工进度确认、跨年度租金及资产外部处置收入确认案例。

### 节点3：不征税收入与免税收入

| 类型 | 核心内容 |
|---|---|
| 不征税收入 | 财政拨款；依法收取并纳入财政管理的行政事业性收费和政府性基金；符合条件的专项用途财政性资金 |
| 专项财政资金 | 需有明确专项用途、专门资金管理办法或具体管理要求，并单独核算 |
| 不征税收入对应支出 | 形成的费用不得税前扣除；形成的资产，其折旧、摊销不得税前扣除 |
| 5年规则 | 作为不征税收入处理的财政性资金，在5年内未支出且未缴回的部分，应计入第6年的应税收入总额 |
| 国债及地方政府债券利息 | 符合规定的利息收入免税；转让所得不当然免税 |
| 居民企业股息红利 | 符合条件的居民企业直接投资收益免税；连续持有上市流通股票不足12个月取得的收益不适用该免税 |
| 非营利组织 | 符合条件的非营利组织收入及其免税收入孳生的银行存款利息等按规定免税 |

计算案例：某企业自行计算应纳税所得额375万元，需转入第6年的财政性资金120万元，另有不得扣除的行政性罚款4万元：

`应纳企业所得税＝（375＋120＋4）×25%＝124.75万元`

## 七、错题重点复盘

### 1. 税法适用原则

- 法律优位：比较法律效力层级，高位法优于低位法。
- 特别法优于普通法：同一事项既有一般规定又有特别规定时，优先适用特别规定。
- 实体从旧、程序从新：旧行为的实体税负按旧法，征收程序原则上按新法。

### 2. 增值税服务分类

| 业务 | 正确税目或处理 |
|---|---|
| 宾馆提供会议场地及配套服务 | 会议展览服务 |
| 武装守护押运 | 安全保护服务 |
| 景区索道、摆渡车、电瓶车、游船 | 文化体育服务 |
| 单用途卡销售或充值 | 预收资金不缴增值税；可开普通发票，不得开专用发票 |
| 售卡方手续费等收入 | 按规定缴纳增值税 |

记忆：**售卡不征税，普票可以开；专票不能开，手续费要纳税。景区“索摆电游”，全部归文体。**

### 3. 企业所得税所得来源地

- 租金、利息、特许权使用费：看负担或支付所得的一方所在地。
- 动产转让：看转让动产的企业或机构、场所所在地。
- 权益性投资资产转让：看被投资企业所在地。
- 股息、红利：看分配所得的企业所在地。

### 4. 开场综合错题数字卡

| 项目 | 记忆结论 |
|---|---|
