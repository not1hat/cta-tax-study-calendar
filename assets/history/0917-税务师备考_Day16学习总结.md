## 二、今日核心学习内容

### （一）税法（一）：土地增值税

#### 节点1：征税范围、收入与税率

| 模块 | 核心结论 |
|---|---|
| 征税判断 | 国有房地产＋权属转移＋取得收入 |
| 征税事项 | 转让国有土地使用权；新房、存量房转让；抵押期满以房抵债；合作建房后转让等 |
| 不征事项 | 国有土地出让、集体土地转让、出租、抵押期间、评估增值、继承、代建房等 |
| 收入 | 货币收入、实物收入、无形资产收入及其他经济利益 |
| 实物收入 | 按取得收入时的市场价格折算 |
| 代收费用 | 计入房价的一并计入收入；房价外单独收取的可不计收入 |
| 税率 | 四级超率累进：30%/40%/50%/60%，速算扣除系数0/5%/15%/35% |

#### 节点2：扣除项目

| 转让类型 | 扣除项目 |
|---|---|
| 房企销售新建房地产 | 土地成本＋开发成本＋开发费用＋有关税金＋20%加计扣除 |
| 非房企销售新建房地产 | 土地成本＋开发成本＋开发费用＋有关税金，不享受20%加计扣除 |
| 旧房评估法 | 评估价格＋土地成本＋有关税金＋评估费 |
| 旧房发票法 | 发票金额每年加计5%＋有关税金；符合条件的原购房契税可扣但不参与加计 |
| 未经开发土地 | 土地成本＋转让有关税金 |

开发费用：

- 能分摊利息且有金融机构证明：`允许扣除利息＋（土地成本＋开发成本）×5%以内`；
- 不能分摊或不能提供证明：`（土地成本＋开发成本）×10%以内`；
- 20%加计扣除仅适用于符合条件的房企销售自行开发的新建房地产。

旧房发票法年数：每满12个月计1年；超过整年后的余数超过6个月，可再按1年计算。

#### 节点3：应纳税额计算

1. `增值额＝应税收入－扣除项目金额`；
2. `增值率＝增值额÷扣除项目金额×100%`；
3. 根据增值率选择税率及速算扣除系数；
4. `土地增值税＝增值额×税率－扣除项目金额×速算扣除系数`。

临界点：增值率恰好50%、100%、200%时，分别仍属于第一、第二、第三档。

综合案例结果：收入8,000万元、扣除项目4,675万元，增值额3,325万元，增值率71.12%，应纳土地增值税1,096.25万元。

### （二）税法（二）：个人所得税分类所得

#### 节点1：利息、股息、红利及偶然所得

| 模块 | 核心结论 |
|---|---|
| 基本计税 | 每次收入额×20%，一般不得扣除费用 |
| 上市公司股息 | 持股≤1个月全额计入；1个月以上至1年减按50%；超过1年暂免 |
| 免税利息 | 国债、国家发行金融债券、符合条件的地方政府债券、储蓄存款利息等 |
| 铁路债券 | 符合条件的利息减按50%计入应纳税所得额 |
| 偶然所得 | 得奖、中奖、中彩、担保收入、外部随机赠礼、抽奖等 |
| 彩票 | 单次不超过1万元暂免；超过1万元全额按20%计税 |

#### 节点2：财产租赁所得

扣除顺序：**税、租、修、费用**。

| 项目 | 规则 |
|---|---|
| “次” | 一个月内取得的收入为一次 |
| 收入≤4,000元 | `（收入－税费－转租租金－修缮费－800）×税率` |
| 收入＞4,000元 | `（收入－税费－转租租金－修缮费）×80%×税率` |
| 修缮费 | 每月最多扣800元，未扣完可在以后月份继续扣除 |
| 居民住房 | 按市场价格出租适用10%税率 |
| 其他财产 | 一般适用20%税率 |

#### 节点3：财产转让所得

`应纳税额＝（转让收入－财产原值－合理费用）×20%`

| 类型 | 核心规则 |
|---|---|
| 普通财产 | 原值按购进价、运输安装费及有关税费确定 |
| 债券 | 多次购入同一种债券，转让部分采用加权平均法确定原值 |
| 打包债权 | 按当次处置债权账面价值占总账面价值的比例分摊购置成本 |
| 股权 | 多次取得同一企业股权采用加权平均法；收入明显偏低且无正当理由时可核定 |
| 核定顺序 | 净资产核定法→类比法→其他合理方法 |
| 住房 | 收入减房屋原值、合理费用及转让税金后按20%计税 |
| 住房免税 | 自用5年以上且为家庭唯一生活用房 |
| 商品房装修费 | 最高按房屋原值10%扣除 |

## 六、需进入后续错题池的知识点
