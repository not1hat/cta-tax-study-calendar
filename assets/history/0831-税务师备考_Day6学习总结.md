### （二）点名复习内容

#### 1. 非居民企业税率

| 情形 | 税率处理 |
|---|---|
| 境内有机构、场所，所得与其有实际联系 | 25% |
| 境内无机构、场所，取得境内来源所得 | 法定20%，通常减按10% |
| 境内有机构、场所，但该项所得与其无实际联系 | 法定20%，通常减按10% |

判断关键：`境内有机构、场所＋所得与其有实际联系`，才适用25%。

#### 2. 职工教育经费

| 项目 | 一般扣除限额 | 超额处理 |
|---|---:|---|

| 工会经费 | 工资薪金2% | 不得结转 |

### （三）税法（一）：进项税额调整

#### 1. 不得抵扣、转出、转入

| 状态 | 税务处理 |
|---|---|
| 购进时即专用于不得抵扣项目 | 从一开始不得抵扣 |
| 原来允许抵扣，后来发生非正常损失 | 转出对应进项税额 |
| 原来允许抵扣，后来改为专用于不得抵扣项目 | 按规定转出 |
| 原来不得抵扣，后来改为一般计税项目 | 符合条件时恢复抵扣 |

普通货物、服务已抵扣后发生非正常损失或用途改变：能直接确定原抵扣税额的，转出对应税额；无法直接确定的，根据当期实际成本计算应扣减的进项税额。

#### 2. 非正常损失

非正常损失主要包括：

- 因管理不善造成货物被盗、丢失、霉烂变质；
- 因违反法律法规造成货物或者不动产被依法没收、销毁、拆除。

对应项目包括：

- 非正常损失的购进货物及相关加工修理修配、运输服务；
- 非正常损失的在产品、产成品耗用的购进货物及相关服务；
- 非正常损失的不动产及其耗用的货物、建筑服务；
- 非正常损失的不动产在建工程耗用的货物、建筑服务。

自然灾害造成的损失，不因其本身直接认定为上述非正常损失。

#### 3. 普通货物、服务兼营无法划分

同时用于一般计税、简易计税、免税和不得抵扣非应税交易，且无法准确划分的：

```text
不得抵扣进项税额
= 无法划分的全部进项税额
  ×（简易计税销售额＋免税销售额＋不得抵扣非应税收入）
  ÷（全部销售额＋全部非应税交易收入）
```

逐期计算，并在次年1月申报期进行全年汇总清算。

#### 4. 长期资产进项税额

长期资产包括固定资产、无形资产和不动产。

| 用途 | 处理 |
|---|---|
| 专用于一般计税项目 | 按规定全额抵扣 |
| 专用于五类不允许抵扣项目 | 不得抵扣 |
| 原值不超过500万元、用于混合用途 | 按规定全额抵扣 |
| 原值超过500万元、用于混合用途 | 购进时先全额抵扣，之后逐年调整 |

五类不允许抵扣项目：

1. 简易计税项目；
2. 免税项目；
3. 不得抵扣非应税交易；
4. 集体福利；
5. 个人消费。

用途改变计算：

```text
不得抵扣或可恢复抵扣的进项税额
= 长期资产对应进项税额 × 净值率

净值率
= 用途改变当月期初净值 ÷ 长期资产原值
```

原值超过500万元的混合用途长期资产调整年限：

| 资产 | 调整年限 |
|---|---:|
| 不动产、土地使用权 | 20年 |
| 飞机、火车、轮船 | 10年 |
| 其他长期资产 | 5年 |

### （四）税法（一）：农产品核定扣除

#### 1. 普通凭票抵扣与核定扣除

| 方法 | 核心口径 |
|---|---|
| 普通凭票计算抵扣 | 购进时按买价和扣除率计算 |
| 核定扣除 | 根据实际生产耗用、成本或销售数量核定 |

一般凭票抵扣：购进免税农产品通常按买价×9%计算；实际用于生产或委托加工13%税率货物时，再加计1%。

#### 2. 继续生产货物

| 方法 | 计算核心 |
|---|---|
| 投入产出法 | 销售货物数量×单耗数量×平均购买价×扣除率÷（1＋扣除率） |
| 成本法 | 主营业务成本×农产品耗用率×扣除率÷（1＋扣除率） |
| 参照法 | 新办企业或新增产品参照同行业单耗或耗用率，次年核定调整 |

```text
当期农产品耗用数量
= 当期销售货物数量 × 农产品单耗数量

农产品耗用率
= 上年投入生产的农产品外购金额 ÷ 上年生产成本
```

投入产出法、成本法的扣除率根据产成品适用税率确定，可为9%或13%，并非一律9%。

#### 3. 直接销售

```text
允许抵扣进项税额
= 当期销售农产品数量 ÷（1－损耗率）
  ×平均购买单价×9%÷（1＋9%）

损耗率
= 损耗数量 ÷ 购进数量
```

#### 4. 用于生产经营且不构成货物实体

```text
允许抵扣进项税额
= 耗用农产品数量×平均购买单价×9%÷（1＋9%）
```

适用于包装物、辅助材料、燃料、低值易耗品等用途。

### （五）税法（二）：固定资产计税基础

| 取得方式 | 计税基础 |
|---|---|
| 外购 | 购买价款＋相关税费＋达到预定用途前发生的其他支出 |
| 自行建造 | 竣工结算前发生的支出 |
| 融资租入且约定付款总额 | 约定付款总额＋签订合同发生的相关费用 |
| 融资租入但未约定付款总额 | 资产公允价值＋签订合同发生的相关费用 |
| 盘盈 | 同类固定资产的重置完全价值 |
| 捐赠、投资、非货币交换、债务重组 | 公允价值＋支付的相关税费 |

可抵扣增值税进项税额不计入固定资产计税基础；不得抵扣的增值税通常计入资产成本。

改建处理：

- 未足额折旧的自有固定资产：改建支出增加计税基础；
- 已足额折旧固定资产的改建支出：按长期待摊费用处理；
- 租入固定资产的改建支出：按长期待摊费用处理；
- 推倒重置：原固定资产净值按规定并入重置后固定资产计税成本。

### （六）税法（二）：不得折旧项目

1. 房屋、建筑物以外未投入使用的固定资产；
2. 经营租赁方式租入的固定资产；
3. 融资租赁方式租出的固定资产；
4. 已足额提取折旧仍继续使用的固定资产；
5. 与经营活动无关的固定资产；
6. 单独估价作为固定资产入账的土地；
7. 其他不得计算折旧扣除的固定资产。

记忆口诀：`房外闲、经租入、融租出、提足用、经营外、单估地`。

租赁判断：经营租赁看出租方折旧，融资租赁看承租方折旧。

### （七）税法（二）：固定资产折旧

```text
年折旧额
=（固定资产计税基础－预计净残值）÷折旧年限

月折旧额
= 年折旧额÷12
```

折旧规则：

- 原则上采用直线法；
- 投入使用月份的次月开始折旧；
- 停止使用月份的次月停止折旧；
- 预计净残值合理确定后，原则上不得变更。

最低折旧年限：

| 资产类别 | 最低年限 |
|---|---:|
| 房屋、建筑物 | 20年 |
| 飞机、火车、轮船、机器、机械和其他生产设备 | 10年 |
| 器具、工具、家具 | 5年 |
| 飞机、火车、轮船以外的运输工具 | 4年 |
| 电子设备 | 3年 |

速记：`房20、机10、器5、车4、电3`。

会计折旧年限短于税法最低年限：超出税法允许扣除额的会计折旧应纳税调增；会计年限长于税法最低年限时，通常按会计实际折旧额扣除。符合加速折旧等专项政策的，按专项规定处理。

### （八）双科串联

| 问题 | 增值税 | 企业所得税 |
|---|---|---|
| 购入固定资产 | 判断进项税额能否抵扣 | 确定资产计税基础 |
| 可抵扣增值税 | 从销项税额中抵扣 | 不计入资产计税基础 |
| 不得抵扣增值税 | 不得抵扣或转出 | 通常计入资产成本 |
| 使用期间 | 用途改变可能调整进项 | 按计税基础折旧 |
| 非正常损失 | 调整相关进项税额 | 判断资产损失扣除条件 |

核心记忆：`增值税关心税额能否抵，企业所得税关心成本如何扣。`
