## 三、税法一学习内容

### 节点1：关税减免与征收管理

| 知识点 | 核心结论 |
|---|---|
| 法定免税 | 免税额度内一票货物、无商业价值广告品和货样、外国政府或国际组织无偿赠送、运输工具途中必需物资、放行前灭失等 |
| 法定减税 | 放行前损坏的货物按海关认定的受损程度减税 |
| 减免税监管期 | 船舶飞机8年、机动车辆6年、其他货物3年 |
| 缴税期限 | 完成申报之日起15日内；符合条件并担保可汇总缴税 |
| 滞纳金 | 滞纳税款×滞纳天数×0.5‰ |
| 税收保全 | 有不能缴税风险且不提供担保时，可冻结、查封、扣押 |
| 强制执行 | 逾期并经限期缴纳仍不缴纳，可划拨存款或拍卖、变卖财产抵税 |

计算案例：300,000元关税逾期8日，滞纳金＝300,000×8×0.5‰＝1,200元。

节点检测：6/6，100%。

### 节点2：退还、补征、追征、复议和责任

| 知识点 | 核心结论 |
|---|---|
| 一般多缴退税 | 纳税人自缴税之日起3年内书面申请 |
| 特殊退税 | 品质、规格、不可抗力原状退运以及出口未装运退关等，通常在1年内申请 |
| 补征 | 一般少征、漏征适用现行3年期限 |
| 追征 | 因纳税人或扣缴义务人违反规定少征漏征，3年内追征并按日加收万分之五滞纳金；走私不受期限限制 |
| 征税争议 | 先申请行政复议，对复议决定不服再诉讼 |
| 复议期限 | 一般申请期60日；普通程序60日，符合条件可延长30日；简易程序30日 |
| 法律责任 | 妨碍追征欠税可处欠税50%以上5倍以下罚款；应扣未扣可处50%以上3倍以下罚款 |

节点检测：7/8，87.5%。错题：漏选“已征进口关税货物因品质原因在1年内原状复运出境可申请退税”。

### 节点3：基本养老保险

| 知识点 | 核心结论 |
|---|---|
| 企业职工参保 | 企业职工、企业化管理事业单位职工、机关事业单位编外人员等应参保 |
| 灵活就业人员 | 无雇工个体工商户、未在单位参保的非全日制人员等可以参保，由个人缴费 |
| 单位缴费基数 | 本单位职工个人缴费基数之和 |
| 职工个人基数 | 上年度本人月平均工资，按当地平均工资60%保底、300%封顶 |
| 缴费比例 | 单位16%、职工个人8%、灵活就业人员20% |
| 城乡居民养老 | 年满16周岁、不含在校学生，非机关事业单位人员且未被职工养老覆盖；基金由个人缴费、集体补助、政府补贴构成 |

节点检测：5/7，71.43%。错题：灵活就业人员误用8%而非20%；城乡居民参保边界中误选机关事业单位在编人员并漏选未被职工养老覆盖的城镇居民。

税法一节点检测合计：18/21，85.71%。

## 四、税法二学习内容

### 节点1：印花税纳税人、范围和税率

| 知识点 | 核心结论 |
|---|---|
| 合同纳税人 | 对应税合同负有直接权利义务的当事人；担保人、证人、鉴定人通常不属于纳税人 |
| 特殊主体 | 委托贷款为受托人和借款人；拍卖成交确认书为产权人和买受人 |
| 证券交易 | 仅对出让方征收 |
| 应税凭证 | 应税合同、产权转移书据、营业账簿和证券交易 |
| 税率0.05‰ | 借款合同、融资租赁合同 |
| 税率0.3‰ | 买卖、承揽、建设工程、运输、技术合同及部分知识产权转让书据 |
| 税率0.5‰ | 土地使用权出让、土地房屋权属及股权转让；证券交易减半后实际税负0.5‰ |
| 税率1‰ | 租赁、保管、仓储、财产保险合同 |
| 营业账簿 | 实收资本与资本公积合计金额，税率0.25‰ |

节点检测：5/8，62.5%。错题：误将担保人、委托人作为纳税人；误认为再保险合同征税；漏选股权转让书据。

### 节点2：计税依据与应纳税额

| 知识点 | 核心结论 |
|---|---|
| 通用公式 | 应纳税额＝计税依据×适用税率 |
| 增值税 | 凭证中单独列明的增值税税款不计入印花税计税依据 |
| 周转借款 | 按合同规定的最高限额计税 |
| 易货合同 | 按购入金额与销售金额合计计税 |
| 承揽合同 | 定作人提供主要材料时，主要材料不计税；辅助材料费和加工费计税 |
| 运输合同 | 运费计税，不含货物价值、装卸费和保险费 |
| 技术开发 | 只按报酬计税，研究开发经费不计税 |
| 金额变更 | 正式增加的部分补税；正式减少的部分可申请退税或抵税 |
| 多税目凭证 | 分别列明则分别计算；未分别列明则从高适用税率 |

节点检测：7/8，87.5%。错题：将研究开发经费计入技术开发合同计税依据。

### 节点3：减免、境外凭证与征管

| 知识点 | 核心结论 |
|---|---|
| 法定免税 | 副本抄本、法定外交军警凭证、特定农业合同、优惠贷款、公益赠与、非营利医疗采购、个人电商订单等 |
| 小微融资 | 金融机构与小型、微型企业签订的借款合同免税至2027年12月31日 |
| 六税两费 | 小规模纳税人、小型微利企业、个体工商户印花税减半至2027年12月31日，不含证券交易印花税 |
| 境外凭证 | 境内不动产、中国居民企业股权以及符合主体和使用地点条件的动产、知识产权、服务凭证应纳税 |
| 排除 | 完全在境外使用的动产或知识产权、完全在境外发生的服务符合条件时不纳税 |
| 义务时间 | 书立应税凭证或完成证券交易当日 |
| 申报期限 | 按次15日；按季或按年在期满后15日；证券交易按周5日内解缴 |

节点检测：9/10，90%。错题：漏选金融机构与小型、微型企业借款合同的现行免税政策。

税法二节点检测合计：21/26，80.77%。
