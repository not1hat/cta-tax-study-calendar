## 四、税法一学习内容

### 节点1：概述与三项行政事业性收费

| 知识点 | 核心结论 |
|---|---|
| 非税收入特点 | 灵活性、非普遍性、不稳定性、资金使用上的特定性 |
| 水土保持补偿费 | 一般生产建设项目按征占用土地面积一次性计征；水利水电工程水库淹没区不计入 |
| 防空地下室易地建设费 | 应缴额＝应建防空地下室建筑面积×当地征收标准；工业生产厂房及配套设施不属于统一征收对象 |
| 草原植被恢复费 | 应缴额＝征占用草原面积×征收标准；规定范围内草原保护、畜牧业设施和农牧民住房不缴 |

计算案例：50,000平方米用地中水库淹没区12,000平方米，标准1.5元/平方米，应缴水土保持补偿费＝（50,000－12,000）×1.5＝57,000元。

节点检测：**4/4，100%**。

### 节点2：七类政府性基金（费）

| 知识点 | 核心结论 |
|---|---|
| 教育费附加、地方教育附加 | 以实际缴纳增值税、消费税及审核批准的免抵税额为依据；进口环节不计；费率分别为3%、2% |
| 文化事业建设费 | 广告服务＝（全部含税价款和价外费用－含税广告发布费）×3%；娱乐服务不得作该扣除 |
| 残保金 | 人数缺口×工资计征标准；工资上限为当地社平工资2倍；达到1%但未达规定比例按50%缴纳 |
| 可再生能源发展基金 | 除西藏外相应电力用户缴纳；扣除农业生产用电；分布式光伏自发自用电量免收 |
| 水库移民后期扶持基金 | 按计征电量×当地标准；农业生产用电等不计 |
| 核电站乏燃料基金 | 商业运行5年以上压水堆机组；实际上网销售电量×0.026元/千瓦时 |
| 森林植被恢复费 | 公益林为基础标准2倍；城市规划区在已适用标准基础上再乘2，可能形成4倍 |

计算案例：符合条件的核电机组实际上网销售电量2亿千瓦时，应缴乏燃料基金＝2亿×0.026＝520万元。

节点检测：**5/6，83.33%**。错题为森林植被恢复费加倍规则，漏选“城市规划区内公益林可能按基础标准4倍计征”。

### 节点3：资源资产收入及石油相关收入

| 知识点 | 核心结论 |
|---|---|
| 免税商品特许经营费 | 一般按免税商品业务年销售收入1%；海南离岛免税店4% |
| 国家留成油收入 | （总收入－增值税、矿区使用费等）×合同约定比例；中海油按月，中石油、中石化按年 |
| 国有土地使用权出让收入 | 包括出让、补缴土地价款、土地租金等；协议出让最低价一般不得低于基准地价70% |
| 矿产资源专项收入 | 包括矿业权占用费、矿业权出让收益；后者可按收益率或出让金额征收 |
| 海域使用金 | 按用海类型、海域等别和标准计征；军事、公务码头、部分非经营性公益用海等免征 |
| 无居民海岛使用金 | 最低价＝出让面积×使用年限×最低价标准；国防、公务、非经营性教学科研等用岛可免 |
| 石油特别收益金 | ［（月加权平均油价－65）×征收率－速算扣除数］×销售量×汇率 |
| 油价调控风险准备金 | 实际销售数量×征收标准；国际原油价格低于40美元/桶调控下限时启动 |

节点检测：**7/8，87.5%**。第7题选项设置错误，学员计算672万元正确，已按正确作答计分；另错点为国家留成油收入允许扣除增值税、矿区使用费等费用。

税法一节点合计：**16/18，88.89%**。

## 五、税法二学习内容

### 节点1：车船税

| 知识点 | 核心结论 |
|---|---|
| 征税范围 | 包括依法登记的车船，以及依法不需登记但在单位内部场所行驶或作业的机动车、船舶 |
| 跨境租赁 | 境内单位或个人租入外国籍船舶不征；将船舶出租到境外仍征 |
| 不征情形 | 临时入境的外国车船及港澳台车船不征 |
| 免税 | 捕捞、养殖渔船，军警外交等法定车船，符合条件的新能源汽车和新能源船舶 |
| 减半 | 符合条件的节能汽车、挂车、拖船、非机动驳船 |
| 计算 | 应纳税额＝年应纳税额÷12×应纳税月份数；取得所有权或管理权当月起计算 |
| 征收管理 | 按年申报、分月计算、一次性缴纳 |

节点检测：**4/6，66.67%**。错点：单位内部车辆属于征税范围；纯电动乘用车属于“不在征税范围”，不是“免税”。

### 节点2：契税征税范围、纳税人、计税依据

| 知识点 | 核心结论 |
|---|---|
| 征税对象 | 土地使用权、房屋所有权发生权属转移 |
| 纳税人 | 承受土地、房屋权属的单位和个人 |
| 土地使用权转让 | 包括出售、交换、赠与；不包括土地承包经营权和土地经营权转移 |
| 房屋互换 | 等价互换免税；不等价互换由支付差价方按差额纳税 |
| 买卖计税依据 | 合同确定的不含增值税成交价格，包括货币、实物和其他经济利益对应价款 |
| 出让土地计税依据 | 包括出让金、补偿费、安置补助费、城市基础设施配套费等 |
| 赠与等无价格转移 | 税务机关参照市场价格依法核定 |

节点检测：**6/6，100%**。

### 节点3：契税优惠及征收管理

| 知识点 | 核心结论 |
|---|---|
| 特殊关系免税 | 婚姻存续期间夫妻变更、离婚分割共同财产、法定继承人继承免税 |
| 农林牧渔 | 承受荒山、荒地、荒滩用于农林牧渔生产免税 |
| 售后回租 | 金融租赁公司首次承受权属照章征税；合同期满承租人回购免税 |
| 改制 | 企业改制要求原投资主体存续且持股超过75%；事业单位改制要求原投资主体存续且持股超过50% |
| 合并、分立、划转 | 符合投资主体存续或相同等规定条件时免税 |
| 住房优惠 | 家庭唯一住房≤140平方米1%，＞140平方米1.5%；第二套住房≤140平方米1%，＞140平方米2% |
| 纳税义务发生时间 | 签订权属转移合同当天，或取得合同性质凭证当天；生效法律文书导致转移的为文书生效当日 |
| 纳税期限 | 办理权属登记前；不需登记的，自义务发生之日起90日内申报 |

节点检测：**5/7，71.43%**。错点：售后回租首次转移与期满回购的税务处理相反；纳税义务发生时间与申报期限混淆。

税法二节点合计：**15/19，78.95%**。

### 课末错题详解

#### 第7题：核电站乏燃料处理处置基金

公式：

\[
应缴基金=实际上网销售电量\times0.026元/千瓦时
\]

代入：

\[
2亿千瓦时\times0.026元=520万元
\]

正确答案为C。注意“元”换算成“万元”需要除以10,000。

#### 第9题：石油特别收益金

已知月加权平均油价72美元/桶，起征点65美元/桶，征收率25%，速算扣除数0.25美元/桶，销售量10万桶，汇率7：

\[
[(72-65)\times25\%-0.25]\times100,000\times7
=1,050,000元=105万元
\]

正确答案为B。选择122.5万元相当于只计算了价差×25%，漏减速算扣除数0.25美元/桶。
