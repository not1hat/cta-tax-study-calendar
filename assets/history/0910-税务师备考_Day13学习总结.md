## 四、税法（一）学习内容

### 节点1：进口应税消费品

| 知识点 | 简要结论 |
|---|---|
| 纳税人 | 进口人或其代理人 |
| 纳税地点 | 报关地海关 |
| 纳税义务发生时间 | 报关进口时 |
| 缴库期限 | 海关填发进口消费税专用缴款书之日起15日内 |
| 从量计税 | 应纳税额＝进口数量×定额税率 |
| 从价计税 | 组成计税价格＝（关税计税价格＋关税）÷（1－比例税率） |
| 复合计税 | 组成计税价格＝（关税计税价格＋关税＋进口数量×定额税率）÷（1－比例税率） |
| 复合税额 | 组成计税价格×比例税率＋进口数量×定额税率 |
| 进口卷烟 | 先按每条组成计税价格确定等级，再总体组价计算税额 |

计算案例：进口白酒10,000斤，关税完税价格100万元，关税10万元，比例税率20%，定额税率0.5元/斤。

- 从量税＝10,000×0.5＝5,000元。
- 组成计税价格＝（1,000,000＋100,000＋5,000）÷80%＝1,381,250元。
- 消费税＝1,381,250×20%＋5,000＝281,250元。

节点检测：4/4。

### 节点2：卷烟、电子烟批发环节

| 项目 | 卷烟 | 电子烟 |
|---|---|---|
| 批发环节税率 | 11%＋0.005元/支 | 11% |
| 计税方法 | 复合计税 | 从价定率 |
| 计税依据 | 不含增值税销售额和销售数量 | 不含增值税销售额 |
| 纳税人 | 境内从事卷烟批发业务的单位和个人 | 持烟草专卖批发企业许可证并经营电子烟批发业务的企业 |
| 特殊规则 | 批发给零售商征税；批发商之间销售不征；不得扣除生产环节消费税 | 电子烟生产、进口环节税率36% |

计算案例：卷烟批发销售额200万元、数量100万支，批发环节消费税＝200×11%＋100万×0.005＝22.5万元。

节点检测：4/4。

### 节点3：零售环节消费税

| 知识点 | 简要结论 |
|---|---|
| 金银铂钻范围 | 金银首饰、铂金首饰、钻石及钻石饰品 |
| 金银铂钻税率 | 5% |
| 以旧换新 | 按实际收取的不含增值税差价计税 |
| 包装物 | 连同首饰销售时并入销售额 |
| 带料加工 | 先用受托方同类售价；无同类价时组成计税 |
| 超豪华小汽车标准 | 每辆不含增值税零售价格90万元及以上，各种动力类型 |
| 零售环节税率 | 10% |
| 二手超豪华小汽车 | 符合规定的二手车交易不征消费税 |
| 相关价外费用 | 精品、配饰和服务等与购车相关价款计入销售额 |

计算案例：金项链以旧换新实际收取含税差价22,600元，消费税＝22,600÷1.13×5%＝1,000元。

节点检测：4/4。

计算案例：婴幼儿2026年6月出生，一方100%扣除，年度扣除额＝2,000×7＝14,000元。

### 节点2：继续教育与大病医疗

| 知识点 | 简要结论 |
|---|---|
| 学历继续教育 | 境内接受；每月400元；同一学历最长48个月 |
| 本科及以下 | 可选择本人或父母扣除，不得重复 |
| 职业资格继续教育 | 取得符合规定证书的当年定额扣除3,600元 |
| 大病医疗范围 | 与基本医保相关、医保目录范围内的自付部分 |
| 大病医疗公式 | 每人可扣额＝自付金额－15,000元，最高80,000元 |
| 扣除时间 | 年度汇算时扣除 |
| 家庭成员 | 本人、配偶、未成年子女分别计算；父母的医疗支出不能由子女扣除 |

计算案例：丈夫自付90,000元、妻子自付40,000元，均由丈夫申报，扣除额＝75,000＋25,000＝100,000元。

节点检测：4/4。

| 被赡养人 | 年满60岁的父母；子女均已去世的年满60岁祖父母、外祖父母 |
| 独生子女 | 每月3,000元 |
| 非独生子女 | 分摊每月3,000元，每人不超过1,500元 |
| 多位老人 | 总额度不按老人数量倍增 |
